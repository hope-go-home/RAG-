# 第 2 章：文件系统与基本操作

## 2.1 什么是文件系统？

文件系统是操作系统用来**组织和管理文件**的方法。就像图书馆的图书分类系统。

### ⚡ 目录树结构

Linux 的目录是一个**倒挂的树**：

```
/  (根目录，像 C:\ 但更"根")
├── bin/        → 基本命令 (binary)
├── boot/       → 启动文件 (内核、引导加载器)
├── dev/        → 设备文件 (device)
├── etc/        → 配置文件 (editable text config)
├── home/       → 用户主目录
│   ├── alice/
│   └── bob/
├── lib/        → 库文件 (library)
├── media/      → 可移动介质 (U盘、光盘)
├── mnt/        → 临时挂载点
├── opt/        → 可选软件 (第三方)
├── proc/       → 进程信息 (伪文件系统)
├── root/       → root 用户的主目录
├── sbin/       → 系统管理命令 (system binary)
├── srv/        → 服务数据 (service)
├── sys/        → 系统设备信息
├── tmp/        → 临时文件 (临时, 重启清空)
├── usr/        → 用户软件资源 (Unix System Resources)
│   ├── bin/    → 用户命令
│   ├── lib/    → 库文件
│   ├── local/  → 本地安装的软件
│   └── share/  → 共享数据
└── var/        → 可变数据 (日志、缓存)
    ├── log/    → 日志文件
    ├── cache/  → 缓存
    └── spool/  → 队列 (打印、邮件)
```

### ⚡ Windows vs Linux 路径对比

| 概念 | Windows | Linux |
|---|---|---|
| 根目录 | C:\ | / |
| 分隔符 | \ | / |
| 用户目录 | C:\Users\用户名 | /home/用户名 |
| 可执行文件 | .exe | 无后缀 (靠权限) |
| 配置文件 | 注册表 (二进制) | 文本文件 |
| 盘符 | C: D: E: | 全部挂载在 / 下 |

### 绝对路径 vs 相对路径

```bash
# 绝对路径：从根 / 开始
cd /home/username/Documents
ls /etc/apt/sources.list

# 相对路径：从当前位置开始
cd Documents          # 进入当前目录下的 Documents
cd ..                 # 返回上一级目录
cd ../..              # 返回上两级
cd ~                  # 回家 (home 目录)
cd -                  # 回到上一个目录

# 特殊目录
.    # 当前目录
..   # 上级目录
~    # 当前用户的家目录
~alice # 用户 alice 的家目录
-    # 上一个工作目录
```

## 2.2 最常用的文件命令（必须背熟）

### ls — 列出目录内容

```bash
# 基本用法
ls              # 列出当前目录
ls /home        # 列出指定目录
ls -l           # 详细信息（长格式）
ls -a           # 显示所有文件（包括隐藏文件 . 开头）
ls -h           # 人类可读的大小（配合 -l）
ls -t           # 按时间排序
ls -r           # 反向排序
ls -R           # 递归列出子目录

# 常见组合
ls -la          # 显示所有文件的详细信息
ls -ltr         # 按时间倒序（最新的在最后）
ls -lh          # 详细信息+友好大小
```

**ls -l 的输出解析**：
```
-rw-r--r--  1  alice  staff  1024  Jul  7 10:00  file.txt
↑↑↑↑↑↑↑↑↑↑  ↑  ↑     ↑      ↑     ↑            ↑
权限        链接 所有者 组     大小   修改时间     文件名
```

**权限位的含义**（后面第 3 章详讲）：
```
-  rwx  rwx  rwx
↑  ↑    ↑    ↑
类型 所有者  组   其他人
```

类型：
- `-` 普通文件
- `d` 目录
- `l` 符号链接
- `c` 字符设备
- `b` 块设备

### cd — 切换目录

```bash
cd /etc           # 进入 /etc
cd ..             # 返回上级
cd ~              # 回家
cd /              # 去根目录
cd -              # 回上一个目录
cd                # 回家（等同于 cd ~）
```

### pwd — 显示当前路径

```bash
pwd     # 输出：/home/alice/Documents
```

### touch — 创建文件或更新时间戳

```bash
touch newfile.txt       # 创建空文件
touch existing.txt      # 更新文件的时间戳
touch {a,b,c}.txt       # 一次创建 a.txt b.txt c.txt
```

### mkdir — 创建目录

```bash
mkdir mydir                      # 创建目录
mkdir -p a/b/c/d                 # 递归创建（没有 a 就创建 a）
mkdir "My Documents"             # 包含空格要加引号
mkdir dir_{1,2,3}                # 创建 dir_1 dir_2 dir_3
```

### cp — 复制

```bash
cp file1 file2                   # 复制文件
cp file1 dir/                    # 复制到目录
cp -r dir1 dir2                  # 递归复制目录
cp -i file1 file2                # 交互模式（覆盖前询问）
cp -v file1 file2                # 显示复制过程
cp -a dir1 dir2                  # 归档模式（保留所有属性）
cp file1 file2 file3 dir/        # 复制多个文件
```

### mv — 移动或重命名

```bash
mv file1 file2                   # 重命名
mv file1 dir/                    # 移动到目录
mv file1 dir/newname             # 移动并重命名
mv -i file1 dir/                 # 覆盖前询问
mv -u file1 dir/                 # 只移动更新的文件
```

### rm — 删除

```bash
rm file.txt                      # 删除文件
rm -i file.txt                   # 删除前确认
rm -f file.txt                   # 强制删除（不询问）
rm -r dir/                       # 递归删除目录
rm -rf dir/                      # 强制递归删除（小心！）
```

> ⚠️ **最重要的警告**：`rm -rf /` 会删除整个系统！不要在任何教程以外的地方执行。

### cat — 查看文件内容

```bash
cat file.txt                     # 显示整个文件
cat -n file.txt                  # 显示行号
cat file1 file2 > combined       # 合并文件
```

### less — 分页查看（推荐）

```bash
less file.txt                    # 分页查看
# 快捷键：
# 空格 → 下一页
# b    → 上一页
# /xxx → 搜索 xxx
# n    → 下一个搜索结果
# q    → 退出
```

### head / tail — 查看头尾

```bash
head file.txt                    # 显示前 10 行
head -n 20 file.txt              # 显示前 20 行
tail file.txt                    # 显示后 10 行
tail -n 20 file.txt              # 显示后 20 行
tail -f log.txt                  # 实时跟踪（看日志的神器）
```

### file — 查看文件类型

```bash
file document.pdf                # 告诉你文件实际是什么类型
file *                           # 查看当前目录所有文件类型
```

## 2.3 ⚡ I/O 重定向 — Linux 的精髓

### 三个标准流

```
stdin  (0) → 键盘输入
stdout (1) → 屏幕输出
stderr (2) → 错误输出（也是屏幕）
```

### 重定向符号

```bash
# >  — 输出重定向（覆盖）
echo "hello" > file.txt      # 把"hello"写入 file.txt（覆盖原有内容）
ls > list.txt                # 把 ls 的结果保存到文件

# >> — 输出重定向（追加）
echo "world" >> file.txt     # 追加到文件末尾

# <  — 输入重定向
sort < file.txt              # 从文件读取输入
wc -l < file.txt             # 统计文件行数

# 2> — 错误重定向
ls /nonexist 2> error.txt    # 错误信息保存到文件
ls /nonexist 2>/dev/null     # 错误信息扔到黑洞

# &> — 同时重定向 stdout 和 stderr
ls /home /nonexist &> all.txt

# 管道 | — 将一个命令的输出传给另一个命令（最重要！）
ls -la | less                 # 浏览大量文件
ls -la | grep "txt"           # 只显示包含 txt 的行
cat file.txt | wc -l          # 统计行数
ps aux | grep nginx           # 查找 nginx 进程
```

### ⚡ 管道原理（透彻理解）

```
命令1 (stdout) → 管道 | → 命令2 (stdin) → 命令3 ...
                     ↓
             内核中的管道缓冲区
```

管道是 Linux 最伟大的设计之一。每个命令只做一件事，组合起来无所不能。

**实际例子**：
```bash
# 找出当前目录最大的 5 个文件
ls -lhS | head -5

# 统计代码行数（排除空行和注释）
find . -name "*.c" -exec cat {} \; | grep -v "^$" | grep -v "^//" | wc -l

# 查看最耗内存的 10 个进程
ps aux | sort -rnk 4 | head -10

# 实时监控某个程序
watch -n 1 "ps aux | grep nginx"
```

## 2.4 ⚡ 文件描述符（被隐藏的关键概念）

文件描述符是 Linux 中最重要的概念之一。理解它才能理解一切 I/O。

### 什么是文件描述符？

文件描述符是一个**非负整数**，是操作系统给每个打开的文件分配的"编号"。

```bash
# 查看当前 shell 打开的文件描述符
ls -la /proc/$$/fd/
```

输出示例：
```
lrwx------ 1 alice alice 64 Jul 7 10:00 0 -> /dev/pts/0  (stdin)
lrwx------ 1 alice alice 64 Jul 7 10:00 1 -> /dev/pts/0  (stdout)
lrwx------ 1 alice alice 64 Jul 7 10:00 2 -> /dev/pts/0  (stderr)
```

### 文件描述符的工作原理（从 C 语言角度）

```c
#include <fcntl.h>
#include <unistd.h>

int main() {
    // 打开文件，返回文件描述符
    int fd = open("test.txt", O_RDONLY);
    // fd = 3（因为 0,1,2 已经被占了）

    char buffer[1024];
    // 通过文件描述符读取
    read(fd, buffer, 1024);
    
    // 关闭
    close(fd);
    return 0;
}
```

**流程图**：
```
进程 A
  ┌──────────────────────┐
  │  文件描述符表         │
  │  fd 0 → stdin        │
  │  fd 1 → stdout       │
  │  fd 2 → stderr       │
  │  fd 3 → /etc/passwd  │  ← 每个 fd 指向一个"打开的文件描述"
  │  fd 4 → /var/log/syslog│
  └──────┬───────────────┘
         │
         ↓
  ┌──────────────────────┐
  │   系统打开文件表      │  ← 内核维护
  │  (记录文件偏移量等)   │
  └──────────────────────┘
         │
         ↓
  ┌──────────────────────┐
  │   inode 表           │  ← 真正的文件数据
  │   (硬盘上的数据)      │
  └──────────────────────┘
```

### 为什么要有文件描述符？

1. **统一接口**：无论读键盘、写屏幕、操作网络，都用 read/write
2. **安全隔离**：进程不能直接访问其他进程的 fd
3. **权限控制**：打开文件时就确定读写权限

## 2.5 通配符（Glob）

```bash
# *  — 匹配任意多个字符
ls *.txt             # 所有 .txt 文件
ls *                 # 所有文件
rm -rf *             # 删除所有文件（小心！）

# ?  — 匹配一个字符
ls ???.txt           # 三个字符的 .txt 文件
file_?.txt           # file_1.txt file_a.txt 等

# [] — 匹配括号内的任一字符
ls [abc]*            # 以 a b c 开头的文件
ls file_[0-9].txt    # file_0.txt ~ file_9.txt
ls [a-z]*            # 以小写字母开头的

# {} — 花括号展开
echo {a,b,c}         # a b c
cp file.{txt,bak}    # 等价于 cp file.txt file.bak
echo {1..5}          # 1 2 3 4 5
echo {01..10}        # 01 02 ... 10
```

## 2.6 别名（alias）— 偷懒神器

```bash
# 创建别名
alias ll='ls -la'
alias gs='git status'
alias ..='cd ..'

# 查看所有别名
alias

# 取消别名
unalias ll

# 永久保存（写入配置文件）
echo "alias ll='ls -la'" >> ~/.bashrc
source ~/.bashrc
```
