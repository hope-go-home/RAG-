# Linux 从零到精通 — 课程大纲

## 学习目标

本教程的目标是让 **零基础小白** 完全理解：

- Linux 操作系统核心概念
- 命令行使用与 Shell 编程
- 系统原理（进程、内存、文件系统）
- 关键系统调用与 C 语言编程
- 包管理与软件编译安装
- 主流库与框架的设计思想
- 综合实战项目

## 前置要求

- 会开电脑、会打字
- 有好奇心和耐心
- **不需要** 任何编程基础

## 学习方法建议

1. **动手！动手！动手！** — 每个命令都要在终端里敲一遍
2. **先理解原理，再记命令** — 懂了为什么，才能记得住
3. **遇到问题先自己查** — `man` 命令是你最好的老师
4. **做笔记** — 用自己的话复述一遍
5. **循序渐进** — 不要跳着看，每一章都建立在前面基础上

- 每章包含：**原理讲解 → 代码/命令示例 → 原理分析 → 练习**
- 标注 ⚡ 的是核心概念，必须完全掌握
- 标注 🔧 的是动手练习，必须亲自完成
