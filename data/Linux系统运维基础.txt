Linux 系统运维基础

Linux 是互联网公司服务器端的主流操作系统，掌握 Linux 运维技能是后端开发和运维工程师的基本要求。

一、文件系统与权限管理
Linux 采用树形目录结构，一切皆文件。根目录（/）下包含 /etc（配置文件）、/var（日志和可变数据）、/home（用户目录）、/tmp（临时文件）等子目录。Python 脚本可以通过 os 和 pathlib 模块操作 Linux 文件系统——创建目录、遍历文件列表、读写文本文件。文件权限分为读（r）、写（w）、执行（x）三个级别，用 chmod 命令修改。使用 open() 函数在 Python 中打开文件时，除了 'r'（读）和 'w'（写）模式外，还支持 'a'（追加）模式。

二、进程管理与性能监控
ps、top、htop 命令用于查看进程状态和系统资源占用。Linux 进程分为运行、睡眠、停止、僵尸四种状态。GIL 的存在使 Python 多线程在 Linux 上同样受限。使用 multiprocessing 模块可以绕过限制利用多核 CPU。数据库进程（如 MySQL、PostgreSQL）需要定期用慢查询日志分析性能瓶颈——MySQL 的 B+树索引在 Linux 的 ext4 文件系统上的 I/O 性能直接影响查询速度。

三、Shell 脚本与自动化
Bash 是 Linux 默认的命令行解释器。Shell 脚本可以串联 grep（文本搜索）、awk（文本处理）、sed（流编辑）等工具实现自动化的日志分析和数据处理。Python 的 subprocess 模块可以在代码中调用 Shell 命令。crontab 实现定时任务调度，常用于数据库备份、日志轮转等运维场景。

四、网络配置与安全管理
ifconfig 和 ip 命令查看网络接口配置。netstat 和 ss 命令检查端口监听状态。iptables 和 firewalld 是 Linux 防火墙工具。SSH 是远程登录的标准协议，密钥认证比密码认证更安全。Python 的 paramiko 库可以实现自动化 SSH 运维。Fail2ban 扫描日志文件识别暴力破解尝试并自动封禁 IP。
