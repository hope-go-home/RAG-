Python 编程基础与进阶

Python 是一种解释型、面向对象的高级编程语言，由 Guido van Rossum 于 1991 年发布。它设计哲学强调代码可读性和简洁的语法，使用缩进代替花括号来划分代码块。Python 拥有庞大的标准库和活跃的第三方生态，广泛应用于 Web 开发、数据分析、人工智能、自动化运维、科学计算等领域。CPython 是官方参考实现，此外还有 Jython（运行在 JVM）、IronPython（.NET）、PyPy（JIT 编译）等替代实现。

一、基础数据类型与容器
Python 内置整数（int，支持任意精度）、浮点数（float，遵循 IEEE 754 双精度标准）、字符串（str，Unicode 编码，不可变类型）、布尔值（bool，True/False，是 int 的子类）。序列类型包括列表（list，可变有序集合，通过方括号定义）、元组（tuple，不可变有序集合，适合作为字典键或函数多返回值）、字符串。列表支持丰富的方法：append() 追加元素、extend() 合并序列、insert() 在指定位置插入、remove() 按值删除、pop() 弹出末尾或指定位置元素。列表的索引（index）操作通过下标访问，从 0 开始计数——例如 my_list[0] 获取第一个元素，my_list[-1] 获取最后一个元素，my_list.index("target") 返回指定元素首次出现的索引编号。需要注意的是，这里所说的索引（index）指的是列表元素的序号位置，与数据库中的 B+树索引是完全不同的概念。字典（dict）是键值对映射结构，底层基于开放寻址哈希表，Python 3.6+ 保证插入有序。集合（set）基于哈希实现元素去重和数学运算，frozenset 是不可变版本。

二、函数式编程特性
Python 中函数是一等公民，可赋值给变量、作为参数传递、作为返回值。高阶函数包括 map()（映射）、filter()（过滤）、reduce()（归约，需从 functools 导入）。匿名函数使用 lambda 表达式，语法简洁但只能包含单个表达式。闭包（closure）是指内部函数可以访问外部函数的局部变量，即使外部函数已执行完毕。装饰器本质是接受函数返回函数的高阶函数，用于日志记录、性能计时、权限校验、输入验证、缓存等横切关注点。functools.wraps 用于保留被装饰函数的元信息。生成器（generator）通过 yield 关键字实现惰性求值，逐个产生数据而非一次性返回，大幅节省内存。

三、面向对象编程
class 关键字声明类，__init__() 为构造函数，第一个参数 self 代表实例本身。实例变量在 __init__ 中通过 self 定义，类变量直接写在类体中，被所有实例共享。Python 支持多重继承，MRO（方法解析顺序）使用 C3 线性化算法解决菱形继承歧义。super() 函数用于调用父类方法。魔术方法（dunder methods）以双下划线开头结尾——__str__ 定义打印输出、__repr__ 定义调试表示、__len__ 支持 len()、__getitem__ 支持索引访问、__iter__ 支持迭代、__call__ 让实例可调用。property 装饰器实现 getter/setter，封装属性访问逻辑。抽象基类（ABC）通过 @abstractmethod 定义接口契约。

四、异常处理与上下文管理
try-except-else-finally 完整异常处理结构。常见内置异常：ValueError（值错误）、TypeError（类型错误）、KeyError（键不存在）、IndexError（索引越界）、AttributeError（属性不存在）、ImportError（导入失败）。raise from 用于异常链，保留原始异常上下文。with 语句实现上下文管理协议，要求对象实现 __enter__ 和 __exit__ 方法。contextlib.contextmanager 装饰器可将生成器函数转为上下文管理器。文件操作推荐使用 with open() 自动关闭，路径处理使用 pathlib.Path 面向对象操作。

五、数据处理与科学计算栈
pandas 是表格数据处理的事实标准，核心数据结构 DataFrame 和 Series 支持筛选、分组聚合（groupby）、数据透视（pivot_table）、合并连接（merge/join）、时间序列重采样、缺失值填充等操作。numpy 提供 N 维数组 ndarray，底层为连续内存块的 C 语言实现，向量化运算避免了 Python 循环的性能瓶颈。广播（broadcasting）机制允许不同形状的数组进行算术运算。scikit-learn 统一了机器学习模型的训练和预测接口，包含特征预处理、模型选择、交叉验证、超参数调优等完整流水线。PyTorch 和 TensorFlow 是深度学习的主流框架，提供自动微分和 GPU 加速。

六、并发与异步编程
Python 的 GIL（全局解释器锁）限制同一时刻只有一个线程执行 Python 字节码，因此 threading 多线程适用于 I/O 密集型任务但无法加速 CPU 计算。multiprocessing 模块绕过 GIL，通过多进程利用多核 CPU。asyncio 是 Python 3.4+ 的异步 I/O 框架，基于事件循环（event loop）和协程（coroutine），async/await 语法编写异步代码，适合高并发网络请求、WebSocket 长连接等场景。concurrent.futures 提供 ThreadPoolExecutor 和 ProcessPoolExecutor 高层抽象。
