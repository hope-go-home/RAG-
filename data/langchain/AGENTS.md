# Agent 备忘录

## 项目位置
D:\项目\langchain

## 项目用途
LangChain 从零到实战的完整学习教程

## 重要命令
- 运行示例: `python examples/01_basic_llm.py`
- 运行完整应用: `streamlit run chat_app.py`
- 安装依赖: `pip install langchain langchain-openai langchain-chroma pypdf python-docx duckduckgo_search`

## 环境变量
- 需要设置 `OPENAI_API_KEY` 或使用 Ollama 本地模型

## 目录结构
- *.md 文件: 教程文档（00~08）
- examples/*.py: 可直接运行的示例代码
- chat_app.py: 完整实战项目（RAG + Agent）
